# Tech Stack

- **Language**: Python >= 3.13
- **Package Manager**: `uv` (indicated by `uv.lock` and `pyproject.toml`)
- **Key Libraries**:
  - `kiwipiepy` (Korean NLP tokenization and POS tagging)
  - `google-genai` (LLM for contextual translation and Hanja etymology)
  - `genanki` (Generating Anki flashcard decks)
  - `elevenlabs` (Text-to-Speech)
  - `stable-ts` & `faster-whisper` (Audio/subtitle alignment)
  - `pandas` (Data manipulation and CSV handling)
  - `tqdm` (Progress bars)
