# Project Purpose

`learn-korean` is a Korean language learning assistant and toolkit. It provides CLI tools to extract unique Korean vocabulary from texts or subtitles (.lrc), translate them contextually and extract Hanja etymology using LLMs (like Gemini), and generate Anki flashcard decks (.apkg). It also includes features for text-to-speech using ElevenLabs and force-aligning audio with text using stable-ts.
